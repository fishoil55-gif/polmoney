# 폴머니 POLMONEY

경찰 월급 계산기. 계급·호봉과 교대 근무 패턴을 넣으면 예상 실수령액을 계산합니다.

**→ https://fishoil55-gif.github.io/polmoney/**

## 무엇을 계산하나

- 기본급 (2026년 경찰공무원 봉급표 [별표 10])
- 초과·야간·휴일근무수당 — 전월 근무 실적 기준
- 법정수당·실비변상 (위험근무·정액급식비·직급보조비 등)
- 공제 (일반기여금·건강보험·장기요양·소득세)
- 연가저축·초과저축 잔여 이월

근무 캘린더에 교대 패턴을 적용하면 근무일·초과시간·휴일근무일이 자동으로 집계됩니다.

## 만듦새

의존성 없는 단일 HTML 파일입니다. 빌드 과정이 없고, `index.html`을 브라우저로 열면 그대로 동작합니다.
입력값은 브라우저 localStorage에 자동 저장되며 서버로 전송되지 않습니다.

외부에서 받아오는 것은 Pretendard 웹폰트 하나뿐입니다.

## 주의

계산 결과는 **추정치**입니다. 기준소득월액·보수월액·소득세를 비워두면 추정식으로 계산하며,
급여명세서의 실제 값을 넣으면 정확해집니다. 위험근무수당·경찰특수업무수당은 예시 금액입니다.

실제 급여는 소속 기관의 급여명세서를 따릅니다.
